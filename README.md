# Banking Fraud Analytics

## Project Overview

This project analyzes banking transaction data to identify fraudulent patterns and understand factors associated with fraudulent transactions using Power BI.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Analysis

## Dashboard Pages

### Overview
Provides a high-level summary of transaction and fraud metrics.

### Risk Analysis
Analyzes fraudulent transactions based on transaction risk and other relevant factors.

### Fraud Insights
Explores fraud rates across account age, merchant categories, payment methods, and device types.

## Key Insights

- Overall fraud rate: **1.43%**
- Fraud rates vary across transaction risk levels.
- Payment methods show different fraud patterns across merchant categories.
- Fraud rates vary by account age and device type.

## Project Objective

The objective of this project is to analyze banking transactions, identify fraud patterns, and present meaningful insights through an interactive Power BI dashboard.

## Dashboard

The Power BI dashboard contains three interactive pages:

- Overview
- Risk Analysis
- Fraud Insights
